# negative_factor_finder

Статический сайт: вставляете список организаций (названия, ИНН или ОГРН) — получаете Excel-таблицу с отрицательными факторами. Организации по вертикали, факторы по горизонтали; в ячейке, где фактор найден, — расшифровка и источник. Пустая ячейка — фактор не обнаружен, жёлтая — проверить не удалось (это не значит «чисто»).

Факторы: статус ЕГРЮЛ (ликвидация и пр.), недостоверные сведения, массовый адрес и массовый руководитель, РНП, налоговая задолженность, смена руководителя / собственника / адреса за период, исполнительные производства, арбитражные дела в роли ответчика, банкротство, тревожные сообщения Федресурса, проверки с нарушениями, убыток и отрицательный капитал. Источники — в [SOURCES.md](SOURCES.md).

## Программа на компьютере (папка `local/`)

Чтобы запросы к реестрам шли с компьютера пользователя (российский IP, без CORS и прокси):

1. Установить Node.js 18+ (https://nodejs.org).
2. Скачать репозиторий (Code → Download ZIP) и распаковать.
3. Запустить `local/start.bat` (Windows) или `local/start.command` (macOS/Linux). Откроется `http://localhost:8787`.
4. Выбрать режим «Программа на этом компьютере». Автоматически проверяются статус ЕГРЮЛ и РНП, по остальным факторам — ссылки на реестры.
5. Кнопка **«Диагностика»** сохраняет сырые ответы реестров (файл `probe-output.json`) — по нему допиливается разбор остальных реестров.

Всё работает локально, данные никуда не отправляются, кроме самих реестров.

## Режимы

Режим «Открытые источники» (через прокси) убран с интерфейса: без платного API автоматически работал только статус ЕГРЮЛ. Код прокси остался в `worker/`, провайдер — в `js/providers.js`.

- **Демо для показа.** Вымышленные данные с правдоподобными расшифровками и пометками «ДЕМО» (на странице и в Excel) — чтобы показать руководству, как будет выглядеть результат.

На странице два режима:

- **СПАРК (по API-ключу).** Заготовка: выбор режима и поле ключа есть, подключение будет дописано по документации API Интерфакса.

Сайт целиком работает в браузере, без сборки. Ключ можно сохранить в localStorage браузера; в репозиторий он не попадает. Excel собирается на странице (`js/xlsx.js`, без зависимостей). Для разработки: `?dev=1` в адресе показывает ещё режимы «Checko» и «Демо».

## Структура

- `index.html`, `style.css` — страница
- `js/app.js` — интерфейс, запуск проверок, выгрузка
- `js/factors.js` — список факторов (столбцов)
- `js/providers.js` — провайдеры данных и правила определения факторов
- `js/xlsx.js` — генератор .xlsx

## Важно

- Разбор ответа ЕГРЮЛ в режиме «Открытые источники» написан по памяти о формате ответа сайта ФНС и не проверялся на реальном сервере (из среды разработки реестры недоступны); проверен только на подставных ответах.
- Поиск по названию может найти тёзку: ИНН выводится рядом с названием, сверяйте его. Надёжнее вводить ИНН.
- Данные справочные, решения принимайте по первоисточникам.
