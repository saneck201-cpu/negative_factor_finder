# Источники данных

Сайт не обращается к государственным реестрам напрямую (у большинства из них нет открытого API, они закрыты капчей или не отдают CORS-заголовки для браузера). Данные из этих реестров собирает API-провайдер, а сайт показывает результат и ссылку на первоисточник.

| Фактор | Первоисточник (открытый реестр) |
|---|---|
| Ликвидация, реорганизация, исключение, смена руководителя / учредителей / адреса | ЕГРЮЛ/ЕГРИП, ФНС России — https://egrul.nalog.ru |
| Недостоверные сведения, адрес массовой регистрации, массовый руководитель/учредитель, налоговая задолженность, налоговые санкции | ФНС «Прозрачный бизнес» — https://pb.nalog.ru |
| Исполнительные производства | Банк данных исполнительных производств ФССП — https://fssp.gov.ru/iss/ip |
| Арбитражные дела, проигранные суды | Картотека арбитражных дел — https://kad.arbitr.ru |
| Банкротство | ЕФРСБ — https://bankrot.fedresurs.ru |
| Намерения ликвидации, реорганизации, уменьшение капитала и др. | Федресурс — https://fedresurs.ru |
| Недобросовестные поставщики, госконтракты | РНП, ЕИС в сфере закупок — https://zakupki.gov.ru |
| Финансовая отчётность (убыток, отрицательный капитал) | ГИР БО ФНС — https://bo.nalog.gov.ru, Росстат |
| Проверки и нарушения | ФГИС ЕРКНМ — https://proverki.gov.ru |

## Что можно проверить вручную дополнительно (на сайт не подключено)

- Суды общей юрисдикции — ГАС «Правосудие», https://bsr.sudrf.ru
- Реестр дисквалифицированных лиц — https://service.nalog.ru/disqualified.do
- Перечень организаций с признаками фиктивности и реестры санкций (Минфин, РФМ) — https://www.fedsfm.ru
- Реестр залогов движимого имущества — https://www.reestr-zalogov.ru
- Реестр товарных знаков и интеллектуальной собственности — ФИПС
- Новости и упоминания — открытый веб-поиск

## API-провайдер

Сейчас подключён Checko (https://checko.ru, API https://api.checko.ru/v2) — требуется ключ из личного кабинета. Другие провайдеры (DaData, API-ФНС, Контур.Фокус и др.) добавляются новым объектом в `js/providers.js`.
