# Прокси для режима «Открытые источники»

Госреестры не разрешают запросы из браузера с чужих сайтов (CORS), поэтому нужен посредник. Это маленький Cloudflare Worker: он пропускает запросы только к хостам из белого списка (`worker.js`, `ALLOWED_HOSTS`) и добавляет CORS-заголовки. Бесплатного тарифа Cloudflare хватает.

## Развёртывание без командной строки

1. Зарегистрируйтесь на https://dash.cloudflare.com.
2. Workers & Pages → Create → Create Worker → дайте имя → Deploy.
3. Edit code → замените код содержимым `worker.js` из этой папки → Deploy.
4. Скопируйте адрес вида `https://имя.аккаунт.workers.dev`.
5. На сайте в поле «Адрес вашего прокси» вставьте `https://имя.аккаунт.workers.dev/?url=` (с `?url=` в конце).

Чтобы прокси работал только с вашим сайтом, добавьте переменную `ALLOWED_ORIGIN` = `https://saneck201-cpu.github.io` (Settings → Variables).

Если запросы к ФНС идут с зарубежных адресов Cloudflare и блокируются, потребуется российский хостинг для прокси; сам код можно перенести почти без изменений.

## Если Cloudflare не достучался до ЕГРЮЛ (ошибка 522)

ФНС не отвечает зарубежным адресам Cloudflare. Решение — запустить тот же прокси в России: на своём компьютере или на VPS с российским IP.

На своём компьютере (нужен Node.js 18+, https://nodejs.org):

1. Скачайте `worker/server.js` из репозитория.
2. В терминале в папке с файлом: `node server.js`
3. На сайте в поле прокси введите `http://localhost:8787/?url=` и нажмите «Проверить прокси».

Окно с программой должно оставаться открытым, пока вы пользуетесь сайтом. Работает в Chrome, Edge и Firefox; Safari блокирует такие запросы с https-сайтов.

На VPS: `HOST=0.0.0.0 ALLOWED_ORIGIN=https://saneck201-cpu.github.io node server.js` и адрес `https://ваш-домен/?url=` (для https перед программой нужен обратный прокси, например Caddy или nginx).

### Если локальный прокси пишет «fetch failed»

Теперь в тексте ошибки (и в окне с программой) показывается причина в скобках. Частые случаи:
- `UNABLE_TO_VERIFY_LEAF_SIGNATURE` / `CERT_...` — Node не доверяет сертификату ФНС (российский корневой сертификат есть в системе, но Node его не использует). Запустите так: `node --use-system-ca server.js` (Node 22.15+/23.8+) или укажите файл сертификата: `NODE_EXTRA_CA_CERTS=путь\к\сертификату.crt node server.js`.
- `ETIMEDOUT` / `ENOTFOUND` / `ECONNREFUSED` — нет доступа к сайту ФНС с этого компьютера (включён VPN с зарубежным выходом, файрвол, корпоративный прокси). Отключите VPN или откройте https://egrul.nalog.ru в браузере и проверьте, что он грузится.
